For reproducibility, call `random.seed(42)` then `np.random.seed(42)` before generating any values; use `random.sample` for spike placement and `np.random.normal` for noise. Implement a 1D constant-velocity Kalman filter with state vector [altitude, vertical_rate] that smooths the noisy signal and detects anomalies by flagging any point where the absolute measurement innovation exceeds 3× the filter's innovation standard deviation. Write `test_descent.py` using pytest with tests verifying: (a) the Kalman filter RMSE against the true noiseless signal is under 12 ft, (b) all 3 spikes are detected with 0 false positives, (c) the filtered altitude output is monotonically non-increasing, (d) the filter's estimated vertical rate at the final time step is within 1 ft/s of the true constant descent rate (−35,000/1,800 ft/s). Run the tests and fix any failures until they all pass. Save a matplotlib figure `descent.png` showing the true path, noisy readings, filtered result, and detected anomalies as red × markers, and print a JSON summary to stdout with fields: `rmse`, `spikes_expected`, `spikes_detected`, `all_tests_passed`.

Hints:
 - Do not move away from the "3× the filter's innovation standard deviation"
 - Do not make a post-filter filter or artificially clamp to insure "output is monotonically non-increasing"
