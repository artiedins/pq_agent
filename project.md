## Simple python agent harness

We have a simple python agent harness `agent.py`, which we always run with `run_agent.sh` (ie. behind bubble wrap).
We will keep making adjustments to `agent.py`, but we are mostly happy with it and want to avoid large changes.
Any change to the harness notices or system prompts MUST stay in-character both with the stated style guide and with the existing demonstrated writing style.
